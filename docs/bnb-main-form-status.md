## Current Assessment

This is a BNB-side submission-route blocker. Do not send users directly to the
closed form from the public landing page.

The sponsor-track forms on the BNB page are not drop-in replacements for the
main track. Submit through a sponsor form only if the project is intentionally
positioned for that sponsor's challenge.
