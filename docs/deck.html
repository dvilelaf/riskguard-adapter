RiskGuard Adapter

Pre-execution policy verdicts for BNB Chain agents and ERC-8183-style jobs.

Open source BSC testnet deployed Two receipt transactions Manifest-only ERC-8183 evidence payload

Problem

Agents can propose financial actions faster than users can review.

  • Blind trust in agent output is risky.
  • Manual review does not scale.
  • DeFi-specific policy evidence is often missing.
  • Users need checks before signing or settlement.

Solution

RiskGuard turns policy constraints into deterministic verdict receipts.

Checks

  • Chain id
  • Max value
  • Allowed action
  • Contract allowlist
  • Token allowlist
  • Max slippage

Outputs

  • Allow verdict
  • Block verdict
  • Policy hash
  • Proposal hash
  • Evidence hash
  • Manifest metadata

Architecture

Small component, clear place in the agent stack.

Agent intent / job
  -> RiskGuard policy check
  -> Policy Verdict Receipt
  -> ERC-8183 manifest metadata
  -> BSC testnet receipt anchoring

Manifest-only is implemented. Real ERC-8183 job submission and opBNB deployment are follow-up work.

Why BNB

DeFAI and autonomous wallets need composable policy evidence.

  • Reusable guardrail before autonomous DeFi actions.
  • Deterministic evidence for allow/block decisions.
  • BSC testnet anchoring already exists.
  • Small integration surface for agents and wallets.
